# Regenerate Practice / desk offline media

Offline assets only — the desk never calls Comfy or ElevenLabs live.

## Prerequisites

- ComfyUI running (this machine: `http://127.0.0.1:8188`)
- Weights already used for Anointed Staff:
  - Stills: `z_image_turbo_int8_convrot` + `qwen_3_4b_fp8_mixed`
  - Beds: YuE2 `yue2_3b_int8_convrot`
  - Short video (optional): FastH3 `fastvideo_fasth3_8step_v2_pruned_int8_convrot` + MiniMax H3 VAEs / text encoder

Workflow drafts live under `tmp/comfy/` when generated by the agent (not shipped).

## Desk atmosphere still

1. Run z-image turbo (int8 checkpoints) with a quiet study-desk prompt.
2. Copy the PNG to `public/brand/desk-atmosphere.png`.
3. Mystic theme uses this file when present (`src/theme.ts`).

## Meditate bed

1. Run YuE2 text-to-music: instrumental style, short duration (~30–45s), export **mp3**.
2. Copy to `public/audio/practice/bed-meditate.mp3`.
3. Set in `public/audio/practice/manifest.json`:

```json
"beds": { "meditate": "/audio/practice/bed-meditate.mp3", "read": "/audio/practice/bed-read.mp3" }
```

4. Practice → Meditate shows **Bed on/off** when the manifest lists a bed.

## Read bed (Scripture / Extra-canon)

1. Prefer ElevenLabs MCP `compose_music` with `force_instrumental=true`, ~40s, quiet pad / soft piano, no vocals.
2. Or YuE2 with the same quiet instrumental brief.
3. Copy to `public/audio/practice/bed-read.mp3` and list under `beds.read` in the manifest.
4. Scripture Listen chrome and Extra-canon show the same **Bed on/off** preference; the bed ducks under Listen / Hear / guides.

## Spoken cues / guides / Hebrew clips

Keep using ElevenLabs **offline** River (`eleven_multilingual_v2`) into `public/audio/practice/`. Phrase list: `public/audio/practice/phrases.json`. Do not wire live TTS into Practice.

Letter files: `letter-{slug}.mp3` (e.g. `letter-alef.mp3`, `letter-kaf-sofit.mp3`).  
Name files: `name-{slug}.mp3` for Hitchcock featured names.  
Temple: `guide-temple.mp3`.

## Ship size

Trim loops. Prefer short beds over multi-minute songs. Skip FastH3 video in the installable dist unless under ~2 MB after encode.
