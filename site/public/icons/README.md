# Marketing icons

Monochrome SVGs for the Astro landing page, chosen via [icons0.dev](https://icons0.dev/) and served from the Iconify API.

| File | Source | Use |
| --- | --- | --- |
| `book-open`, `hash`, `git-branch`, `kanban`, `sparkles`, `mic`, `library`, `orbit`, `flower-2`, `audio-lines`, `palette` | Lucide (ISC) | Feature catalog |
| `alphabet-hebrew` | Tabler Icons (MIT) | Gematria |
| `clock`, `scroll-text`, `book-marked`, `lock`, `shield` | Lucide | Fence + nav |
| `windows`, `linux`, `apple` | Material Design Icons (Apache-2.0) | OS downloads |
| `download`, `github`, `notebook`, `layout-list`, `lamp-desk` | Lucide | Nav / chrome |

Color is applied with CSS `mask` + `currentColor` (Staff Gold). GitHub README uses the same Iconify CDN URLs tinted `#8f5e24`.
